# 工作卡片

把"AI 现在在干嘛"做成桌面上看得见的东西。

每个活跃会话一张卡片，置顶显示在屏幕上，切到任何窗口都盖不住它。默认贴在屏幕左下角，可拖动，松手后记住位置。

## 卡片长什么样

```
插件安装讨论
● 写文件  window.ps1        12:34
▓▓▓▓▓▓░░░░  3/7 项 · 约 18 分钟
```

- **第一行**：会话标题（会话没有标题时取第一条消息的前 18 个字）
- **第二行**：状态灯 + 当前动作 + 本会话已运行时长
- **第三行**：粗进度条 + 完成项数 + 预计剩余

状态灯：绿色 = 正在跑工具，蓝色 = 模型在思考，灰色 = 空闲。

## 怎么用

- **拖动**：按住卡片任意空白处拖动，松手即记住新位置（按会话 id 存在 `%USERPROFILE%\.dsh\work-cards\positions.json`）
- **关闭**：点右上角的 `×`。关闭只影响这一轮：同一轮里不会再冒出来，等这个会话开始新一轮才会重新出现
- **双击**：把 DSH 窗口切到前台
- 新会话出现时自动加一张卡片；会话 30 分钟没动静后卡片自动消失

## 数据从哪来

读取 `%USERPROFILE%\.dsh\sessions\` 下的会话日志（zstd 压缩的 JSONL），按事件还原：

- 当前动作：最近一次 `tool/call` 没有配对的 `tool/result`，就说明这个工具正在跑
- 进度：最近一次 `todo/write` 快照里已完成项 / 总项
- 预计剩余：最近 3 次"完成数增加"的间隔取平均，乘以剩余项数

## 限制（都是故意的）

- **只有 Windows**：卡片用 PowerShell + WPF 画，不额外下载运行时
- **进度依赖 todo 清单**：助手没列清单时，卡片只显示"进行中"，不编百分比
- **ETA 是估算**：样本少于 2 次时留空；估错时它不会假装准确
- **不显示子代理**：只看根会话，子代理的工作折叠进父会话的"运行命令"里
- **会话日志有约 1 秒延迟**：卡片跟随日志刷新，不是实时事件流
